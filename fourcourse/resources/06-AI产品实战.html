八、30 天行动计划（每周做什么，能产出什么）

一句话原则：每周必须交出一个别人能打开的东西。没有交付物的那一周等于没学。
全部可在「不写代码」前提下完成；预计每周投入 6–8 小时。

第 1 周：建语言 + 建尺子（产出：1 页自评 + 1 篇 500 字拆解）

天做什么用哪条资源
D1读能力模型，给自己五维打分，写下最差 1 项能力模型
D2读 Cursor 拆解，抄它的四问结构Cursor 拆解
D3–D4自己拆一个你天天用的 AI 产品（豆包 / Kimi / 元宝任选），写 500 字，四问必须齐全同上结构 + 案例库模板
D5打开 Artificial Analysis 与 OpenRouter，各截图 1 张，抄下「智能指数 / 每任务成本 / 市场份额」三个数AA · OpenRouter
D6–D7读一遍 token 成本入门，用它的模板给你自己的校园信息聚合爬虫项目估一次月成本（假设用户数、调用次数自己设）llm-cost-101

本周交付：自评表.md（五维 + L1/L2/L3 档位）+ 拆解_某产品.md（500 字）+ 成本估算.md（含假设表）

第 2 周：把 PRD 写出来（产出：1 份能给老师/队友评审的 AI PRD）

天做什么用哪条资源
D1–D2精读 4 万字 AI PRD 那篇，只抓「模型故事 / Agent 工作流程 / 提示词设计 / 评估标准」四个板块AI PRD 模板
D3读 PRD 与交互设计四篇合集，重点抄「兜底/反馈/预期管理三件套」prd-and-design
D4–D6为企业风险预警 Agent 写一份 6–8 页 PRD：模型故事 1 段 + 流程图 1 张 + 时序图 1 张 + 提示词设计 + 评估标准（10 条测试样本）同上
D7用 HAX 的 18 条准则逐条对照自己的 PRD，标出「没考虑到的兜底」HAX Toolkit

本周交付：PRD_风险预警Agent_v1.md（含流程图/时序图/评估集 10 条）

第 3 周：动手做出能用的东西（产出：1 个可分享的 Agent 链接）

天做什么用哪条资源
D1注册扣子，跟官方教程搭一个「校园通知汇总问答」Bot（知识库 + 一个工作流节点）扣子 · 开发文档
D2读提示工程指南的 CoT / Few-shot / RAG / Function Calling 四节，回头改自己的提示词提示工程指南
D3–D5把上周 PRD 里的核心能力，用扣子/Dify 做出最小可跑版本（可以只做 1 个场景、3 个工具）Dify 文档
D6读 Vibe Coding 三篇，判断哪些必须交工程师、哪些自己扛vibe-coding
D7用 Ollama 在本地跑一个开源模型，记录「本地 vs API」在速度、成本、隐私上的实测差别Ollama

本周交付：可分享的 Agent 链接 + 本地vs云API对比.md（含实测算出的成本差）

第 4 周：转成求职资产（产出：作品集首页 + 面试问答稿）

天做什么用哪条资源
D1读作品集方法，把前三周材料编成「1 个项目 = 问题→方案→取舍→效果」作品集
D2–D3刷面试题库的「产品设计题 + 案例题」，每题只写要点 + 追问答案面试题库
D4挑 2 篇最接近你目标岗位的面经（如字节 AI Agent PM 实习、Kimi AI PM），逐题自问自答真实面经
D5读避坑指南，把 10 条面试反问抄成自己的提问卡避坑指南
D6去 BOSS / 字节官网拉 5 条真实 JD，逐条对照能力模型看自己差什么BOSS · 字节

30 天后你应该手握

  1. 1 份 AI PRD（有模型故事、流程图、评估集）— 对应你现在的课题组项目
  2. 1 个能点开就用的 Agent 链接 — 作品集的门面
  3. 1 份 token 成本估算 — 面试里最能区分「懂 AI 产品」和「会用 AI」的一页纸
  4. 3 份拆解笔记 + 20 题问答稿 — 面试时的弹药
下一步（第 5–8 周，不在本册展开）：把 Agent 项目做成有真实用户的小产品，记录使用数据与 badcase，再回来重写一版 PRD —— 有数据的那版才是作品集的主角。
