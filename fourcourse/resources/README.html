一、先看这条：资料库最大的敌人是"收藏了就不看"

我见过太多人的收藏夹——存了 200 个链接，一个没点开。

所以这个库有三条使用规则：

  1. 每周只用 2-3 个资源。不是"有 50 个所以都要看"，是"这周挑 2 个用透"。
  2. 同一个知识点只用一种资料。教材 + 一个视频 + 一个题库，够了。三个视频讲同一个公式 = 浪费时间。
  3. 学完要留痕。在 04_学习记录 写一行：今天用了哪个资源、哪一段、有没有用。三个月后你能看出哪个真有用。

四、什么情况下才去翻更多资料

只有三种情况值得开新资源：

  1. 教材某段看了三遍还是不懂 → 换一种讲法（换视频/换可视化）
  2. 做题卡在同一步 → 找同类例题的详细解答
  3. 想验证自己是不是真懂了 → 找题库自测

除此之外，不要开新资源。教材 + 课件 + 一个辅助，足够应付期末。

五、这个库怎么维护

  • 新找到好资源：直接加到对应分册表格里，注明采集日期
  • 发现链接失效：把状态改成「已失效」并保留一行说明，别直接删（可能换域名了）
  • 每学期末清一次：三个月没用过的资源降级到「历史归档」区

六、边界（说清楚，免得你以为是万能的）

  • 不是真题库。重庆理工的历年期末卷没有公开渠道，网上搜到的"重理工概率论期末"多半是别的学校或机构编的
  • 不含盗版教材 PDF。你的教材是学校订的正版，别去找网盘版
  • 链接会失效。状态是 2026-10-25 的快照，过期了告诉我
  • 资源多 ≠ 学得好。这一条最重要
