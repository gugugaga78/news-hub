七、从零到能演示的三条路径（每周 2 次 × 60 分钟）

前提：他有爬虫底子（会 requests / 解析 / 存文件），所以跳过 Python 基础，直接从「调用模型」开始。三条路选一条走完，不要并行。

路径 A：2 周做出第一个能演示的 RAG Agent（最短、最稳，建议先走这条）

次60 分钟做什么产出 / 验收
第 1 次装 Ollama（Windows 安装包）→ ollama run qwen3:4b 说上话；再申请一个 DeepSeek API key 备用本地模型能对话 + 一次 API 调用成功
第 2 次跑 llm-universe 第 4 章代码（调用 API + 简易问答）终端里能问答，会算 token 成本
第 3 次用 Chroma 把 3–5 份课程 PDF 切块入库，接上问答问"我们课上讲的 XX 是什么"能答对
第 4 次加「引用来源」+ Streamlit 界面（llm-universe 有现成模板）一个能截图的对话框，答案带出处

四条通用避坑（都是国内环境真实会撞的）

  1. pip 换国内源（清华 / 阿里），否则装 chromadb、playwright 会等到放弃。
  2. 模型权重别从 HF 拉，走 ModelScope；Ollama 的模型库本身国内速度可接受。
  3. GitHub 页面能开，但 git clone 大仓库会慢 —— 优先 Download ZIP，或先 clone 小仓库（LightRAG、llm-universe）练手。
  4. 别一上来装 RAGFlow / Milvus 这种要 docker + 大内存的；第 1 个月只碰 Chroma + Ollama，等 demo 跑通了再升级。
