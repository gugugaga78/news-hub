AI基础与理论Coding Agent：为什么代码是最强工具

第 9 周 · 周四 · 2026-11-05 · 建议 60 分钟
🧭 一句话定位：代码是唯一能「组合出无限能力」的工具。会写代码的 Agent，等于拥有了所有工具——因为它可以现场造一个。

本节要掌握什么

  • 代码作为通用工具：一个 execute_code 能替代成百个专用工具
  • 沙箱执行：代码必须在隔离环境跑，限制文件/网络/资源
  • 反馈闭环：报错信息是最好的纠错信号，Agent 靠它自我修复
  • 代码生成的可靠性来自「测试」而非「模型自信」
  • Human-in-the-loop：危险操作（删文件、发请求）要人确认
Coding Agent 循环：写代码 → 执行 → 读报错/结果 → 修改 → 再执行
能力上界 ≈ 模型代码能力 × 可迭代次数

推导 / 解题路径

  1. ① 明确任务边界：要处理什么输入、产出什么输出
  2. ② 让 Agent 先写最小可运行版本，而不是一次写完整
  3. ③ 跑起来看报错，用报错驱动下一轮修改
  4. ④ 通过后补测试用例，防止后续改动破坏功能
📝 例题
让 Agent 处理 100 个 Excel 文件。笨办法：做成 100 个专用工具。聪明办法：给一个 Python 执行器，让它现场写脚本批量处理——一个工具解决所有类似任务。这就是「代码即通用工具」。
⚠️ 沙箱不是可选项。不加限制的代码执行等于把机器交给模型——它能删库、能外传数据。必须限制可访问目录、禁止任意网络、设执行超时。
💡 判断一个 Agent 产品强不强，看它敢不敢让模型写代码并执行。这是能力上限的分水岭。Claude Code、Cursor 的本质都是这个。
