第 1 课：数据从哪来？

今晚你就要做数据标注——先搞懂它为什么重要，晚上干活会特别清醒

⏱ 水课 30 分钟 · 只看不动手

?先想一个问题

一个从没打过网球的人，只靠看 1000 段「错误挥拍 → 教练纠正」的对照视频，能不能学会网球？

能。AI 模型就是这么学东西的。

你标注的每一条数据，本质上就是在给模型看「这样做 ✅ / 那样做 ❌」的对照视频。

1模型到底从数据里学到了什么

一条训练数据长这样：

输入（X）标签（y）
一段挥拍视频 / 一句学生提问动作名称、是否标准、教练回答

模型训练时做的事，用一句话说：

看大量「输入 → 标签」的配对，自己总结出中间的规律。
比如它会慢慢发现：「击球点在身体侧前方 + 拍面垂直」大概率是标准正手。

这个流程叫监督学习——你用标准答案"监督"它。你现在做的标注，就是在生产这些标准答案。

2为什么标注质量 = 模型的天花板

⚠ AI 圈有句铁律：Garbage In, Garbage Out（垃圾进，垃圾出）

如果 100 条数据里有 20 条标错了（比如把"错误动作"标成"标准"），模型学到的规律就是歪的——它不会质疑你，它只会认真地学错。

所以标注前先定好三件事（今晚开干前花 10 分钟）：

  1. 标签清单：一共有哪几类？（如：正手/反手/发球/其他）边界要写清楚
  2. 判断标准：什么算"标准"、什么算"需纠正"？最好配 1-2 个示例
  3. 拿不准怎么办：统一标成"待定"，千万别凭感觉硬标

3数据处理：pandas 五个救命操作

晚上标注完，你一定会想：一共多少条？每类各多少？有没有漏标的？用 pandas 几行代码就能查。回寝室对着敲一遍，不用背。

import pandas as pd

df = pd.read_csv("标注数据.csv")   # 1. 读入数据

df.head()                  # 2. 看前5行长啥样
df.shape                   # 3. 一共多少行、多少列
df.columns                 # 看看字段名

df["动作类型"].value_counts()  # 4. 每类各有多少条 ←最常用
df.isnull().sum()          # 5. 每列有多少空值（查漏标）

df.to_csv("标注数据_已检查.csv", index=False)  # 保存
💡 把这页收藏，晚上处理数据时照着抄。能跑通这 5 行，你就已经会用 pandas 解决 80% 的实际问题了。

430 秒自测

Q：标注时遇到一条动作"看起来有点标准又有点不标准"，最合理的做法是？

✅ 答案：标"待定"。模糊数据硬标 = 主动往模型里灌噪音。100 条干净数据 > 200 条带错数据。
